# KEMET CHESS — Шахматы Древнего Мира

Статическая web-игра: классические правила FIDE (chess.js), 4 цивилизации-скина
(Египет, Вавилон, Эллада, Рим), 2D + 3D доски, ИИ-противник Stockfish WASM
(6 уровней), ИИ-тренер «Оракул», P2P-мультиплеер PeerJS по пригласительной
ссылке, кампания из 12 пазлов, пост-анализ партии. **ZERO BACKEND** — всё
работает из статики на GitHub Pages.

> Статус: **Шаги 0–1 из 10 выполнены** (аудит + scaffold/spike). Далее — по MASTER
